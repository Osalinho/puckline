🔗 Synchronizacja wyników (GitHub)

Ręcznie wpisane wyniki są zapisywane do pliku manual_results.json w Twoim repo na GitHubie — dzięki temu są widoczne na każdym urządzeniu, na którym skonfigurujesz to samo repo i token.
Token jest zapisany wyłącznie lokalnie w tej przeglądarce (localStorage) — nigdy nie trafia do repo ani nikąd indziej poza bezpośrednie zapytania do GitHub API. Potrzebny jest token typu „Fine-grained" z uprawnieniem Contents: Read and write ograniczonym do tego jednego repozytorium — wpisz ten sam token na każdym urządzeniu, z którego chcesz korzystać.
